# A 2D level editor
A 2D level editor used by game developers to design grid-based maps and video game levels

# Preview


# How to run locally

Clone this repo and run 
```
npm install
npm run dev
```

### AI DISCLOSURE
**No LLM/AI was used in the making of this project.**
